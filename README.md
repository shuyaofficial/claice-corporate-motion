## 手元で見比べる

このリポジトリをクローンするか、GitHubの「Code → Download ZIP」からダウンロードして展開してください。次のHTMLをブラウザで直接開けます。

| 開くファイル | 試せること |
| --- | --- |
| [動きの比較/index.html](動きの比較/index.html) | 第3版と実験版をPC・スマホの実画面で比較。各場面へのリンク、本採用したい動きと読みづらさのアンケート |
| [動きの実験版/index.html](動きの実験版/index.html) | 円卓から事業へスクロールし、模型を左右にドラッグ。事業・育成・採用からフォームまでたどれる全ページ版 |

実験版のヘッダーから動きを停止できます。端末の「視差効果を減らす」にも対応しています。応募・お問い合わせフォームはローカルで入力と確認を試すためのものです。アンケート回答はブラウザに保存され、「回答をコピー」で取り出せます。

## 実験版を再ビルドする

Node.js 22.23.4以上とnpmを用意し、リポジトリのルートから次を実行します。

```sh
cd アセット/site-A4
npm ci
npm run build
```

Astroのページとコンポーネントは `アセット/site-A4/src/`、GIFやGLBなどの素材は `public/` にあります。ビルド時には隣の `アセット/content/` と `アセット/3d/layout.json` を読み込み、ルートの `動きの実験版/` に書き出します。
